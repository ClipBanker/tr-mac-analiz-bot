# Бот-контентщик для футбольного канала (Турция)

Бот сам ведёт Telegram-канал на турецком языке:

| Когда (по Стамбулу) | Что публикует |
|---|---|
| каждые 3 часа (кроме 01:00–09:00) | разбор и прогноз на ближайший интересный матч (MS 1/X/2, ÇŞ, 2.5 Üst/Alt, KG Var/Yok) с коэффициентом и «звёздами» уверенности |
| ~09:00 | «Dünün özeti»: итог вчерашних прогнозов (✅/❌ и общий процент) |
| 10:00–12:00 | «Günün maçları»: анонс матчей дня |
| через ~2 часа после старта матча | результат: «✅ TUTTU» или «❌ tutmadı» |

Сначала бот берёт матчи турецких клубов и сборной, потом лиги из списка, а если там пусто (например, пауза на сборные), то матчи других крупных лиг. Женские, молодёжные и резервные турниры не берёт. **Ручной запуск** (Actions → betting-bot → Run workflow) публикует прогноз сразу, без ожидания интервала.

**Сервер не нужен.** Бот запускается бесплатно на GitHub Actions раз в час: просыпается, делает нужное и засыпает.

**Откуда данные.** Матчи, форма команд, очные встречи, вероятности и коэффициенты берутся из API-Football (бесплатный тариф — 100 запросов в день, боту хватает ~25–35). Текст разбора пишет нейросеть строго по этим данным. Если ключа нейросети нет или она не ответила, бот пишет разбор по шаблону, и канал не простаивает.

**Ограничения в постах.** Слова «garanti», «%100», «kesin kazanç», «şike» отсекаются фильтром. В каждом посте стоит подпись 18+. Ссылок на букмекеров бот не ставит.

## Что нужно (всё бесплатно)

1. **Telegram-канал и бот.** В @BotFather создайте бота (`/newbot`), скопируйте токен. Добавьте бота в канал **администратором** с правом публиковать сообщения.
2. **Ключ API-Football.** Зарегистрируйтесь на dashboard.api-football.com (карта не нужна) и скопируйте ключ: Account → My Access.
3. **Ключ нейросети (желательно).** Бесплатный ключ Gemini в Google AI Studio (aistudio.google.com → Get API key). Подойдут и Claude или OpenAI: это платно, но копейки, около 4 запросов в день.
4. **Аккаунт GitHub.**

## Запуск за 10 минут

1. На GitHub создайте **приватный** репозиторий (New repository → Private).
2. Загрузите в него все файлы из этого архива (Add file → Upload files), **включая скрытую папку `.github`**.
   Если загрузчик в браузере не видит `.github`, создайте файл вручную: Add file → Create new file, имя `.github/workflows/bot.yml`, и вставьте содержимое из архива.
3. Settings → Secrets and variables → Actions → **New repository secret**. Добавьте четыре секрета:

   | Имя | Значение |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | токен от BotFather |
   | `TELEGRAM_CHANNEL` | `@username_канала` (для закрытого канала числовой id вида `-100…`) |
   | `API_FOOTBALL_KEY` | ключ API-Football |
   | `LLM_API_KEY` | ключ Gemini (или оставьте пустым, тогда разбор пишется по шаблону) |

4. Settings → Actions → General → Workflow permissions → **Read and write permissions** → Save. Без этого бот не сможет запоминать, что уже опубликовал.
5. Вкладка **Actions** → betting-bot → **Run workflow**. Это первый ручной запуск, дальше бот работает сам каждый час.

## Настройка (файл `config.yaml`)

- `leagues`: какие лиги брать и в каком порядке приоритета. По умолчанию Süper Lig, еврокубки, Кубок Турции, топ-5 лиг Европы.
- `priority_teams`: матчи этих клубов всегда идут первыми (Galatasaray, Fenerbahçe, Beşiktaş, Trabzonspor…).
- `max_predictions_per_day`: сколько прогнозов в день (по умолчанию 4).
- `post_interval_hours`: как часто постить (по умолчанию 3 часа). `quiet_hours`: ночные часы без постов. `digest_hour`: время анонса.
- `fallback_any_league`, `fallback_countries`: брать ли матчи других лиг, когда в основных пусто, и из каких стран в первую очередь.
- `llm_provider`: `gemini` / `anthropic` / `openai` / `none`. `llm_model`: модель, пусто = по умолчанию.
- `min_odd` / `max_odd`: в каком диапазоне коэффициентов выбирать прогноз.
- `channel_name`, `disclaimer`: подписи.

Правки можно делать прямо на GitHub: открыть файл → карандаш → Commit.

## Проверка без отправки в канал

```bash
pip install -r requirements.txt
# на тестовых данных из папки mock/ (интернет и ключи не нужны):
BOT_STATE_FILE=/tmp/test_state.json python bot.py --mock --dry-run --now "2026-11-15 14:05"
# на живых данных, но без публикации:
API_FOOTBALL_KEY=... python bot.py --dry-run
```

## Что важно знать

- **Время.** Расписание GitHub иногда запускается с опозданием на 5–15 минут, поэтому прогноз выходит не ровно за 3 часа до матча, а за 2½–3 часа. Для канала это некритично.
- **Лимит Actions.** Приватный репозиторий на бесплатном GitHub получает 2000 минут в месяц, бот тратит около 750. Запас большой.
- **Если что-то сломалось**, смотрите вкладку Actions → последний запуск → лог шага «Run bot». Там видно, сколько матчей выбрано, что пропущено и почему.
- **Бот публикует и попадания, и промахи**: открытая статистика держит доверие аудитории лучше, чем одни «заходы».
